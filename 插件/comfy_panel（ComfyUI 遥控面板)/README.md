# ComfyUI 联动 · 主程序插件（顶栏主模式）

**显示 ComfyUI 生成的照片**、控制**开始 / 停止**、看**运行进度**、把**选中的图片送进工作流**。

## 显示方式

和「标签库 / 打标模式」一样，是**顶栏的一个模式按钮 + 占满主区的整块视图**：顶栏「标签库」后面会出现 `ComfyUI`，点一下切换过去；主区全宽，左侧标签栏在这两个新模式下隐藏。**「🧩 插件」浮层里不再有这一页**（浮层只剩「标签库工具」）。

顶栏按钮与面板均**不带功能图标**（应用户要求删除）；操作按钮上的小图标仍保留。

这是运行时注册出来的，不是写死在主程序里：`panel.js` 顶部的幂等引导会往 `.modes` 加按钮、往 `main.main` 加 `section.panel.col-right`，把 `panel.html` 的内容搬进主视图，并包装一次 `switchMode` / `renderPlugins`。所以：

- **主程序一行未改**（`index.html` / `app.js` / `core\` 全没动），不用重新打包 exe
- 删掉本文件夹 → 顶栏按钮、主视图一起消失，不会留死按钮；另一个插件（照片库）照常
- 热检测重建插件浮层时会重新摘掉自己的页签，不会冒回浮层里
- **小窗口适配**：顶栏按钮变多后窄视口会挤成两行，所以插件注入了 3 段响应式 CSS（`1200 / 1040 / 900px` 断点）：压缩按钮间距字号、隐藏 `#tip` 与重复按钮（`📋 全局填入`、`📚 标签库`、`🌓 主题`），保证顶栏始终 48px 单行、文字不折行。样式由插件注入，插件全删时一起移除、装回时自动恢复；`style.css` 未改

## 架构（重要）

**纯前端插件。** 面板 JS 只 `fetch` ComfyUI 节点包注册的 `/chip/*` 路由，不调用主程序后端 `api()`、不需要新增依赖。

```
插件\comfy_bridge\   ← ComfyUI 那边装（custom_nodes），注册 /chip/* 路由 + 联动节点（大模型/LoRA/图像输入/生成图返回/【Latent(联动)】）
插件\comfy_panel\    ← 本插件，装在主程序 插件\ 目录
插件\photo_library\  ← 独立照片库插件（可选）
```

安装：把 `comfy_panel` 文件夹放在**主程序**的 `插件\` 下（源码启动 = 项目根 `插件\`；exe = exe 旁 `插件\`）。改了 `panel.js` 内容后需**重启一次程序**（插件脚本只注入一次）。

## 用法

1. 顶部地址默认 `127.0.0.1:8188`，但**不用手填端口**：启动时和点「🔌 连接测试」会自动探测 `8188 / 8189 / 8199 / 8181 / 8080 / 8000`，命中 `/chip/ping` 就自动改地址并记住（秋叶启动器常带 `--port 8189`）。看到 **已连接 ✓** 才说明 `comfy_bridge` 装好并重启过 ComfyUI
2. **▶ 开始** = 默认**运行当前画布**：读取 ComfyUI 界面上正在编辑的活画布，经浏览器排队通道提交（等价于用户手点「运行」，节点高亮 / 按钮变色 / 预览全正常）；**■ 停止** = 中断（入口在顶栏 `ComfyUI` 模式里）
3. 跑完点「🔄 刷新生成图」（执行结束也会自动刷一次）→ 生成图网格里点一张选中
4. **送图进工作流** 三个来源：
   - 「📚 用照片库选中图」→ 读照片库插件的选中项
   - 「📂 从磁盘挑一张」→ 系统选图，直接上传
   - 「🖼️ 用选中的生成图」→ 把刚生成的图送回去再跑（图生图 / 放大）
5. 面板「宽 / 高」数字框 → 注入到 ComfyUI 画布上的 **`Latent(联动)`** 节点（输出 ComfyUI 通用 `LATENT`，直连 KSampler 的 `latent_image`，可取代「空Latent」）
   - 04 区有 **「预设尺寸」下拉**（SDXL / SD1.5 标准比例桶，同 Comfyroll「宽高比」节点）+ **「⇄ 互换」** 按钮：选中即填入宽/高，可再加「互换」一键横竖翻转，之后仍可手改微调
6. 送进去后，在 **ComfyUI 画布上把「输入图片」节点手动连到**需要图片的位置，再点开始

## 边界

- 生成图**只显示、不落盘**，也不自动存进照片库；关掉浮层就没了（ComfyUI 自己 `output\` 里的原文件仍在）
- 「开始」复用最近一次工作流：**在 ComfyUI 里改了画布，先在那边点一次 Queue**，之后主程序才跟着最新工作流跑
- 进度是**阶段式**（排队 20% / 执行 60% / 完成 100%），不接 WebSocket，拿不到逐采样步百分比
- 进度条与状态每 1.5 秒轮询一次 `/chip/status`，ComfyUI 没开时安静显示「离线」，不弹错误
- 照片库插件删掉后，本插件仍可用（只是「用照片库选中图」会提示没选中）；反之亦然

## 排错

| 现象 | 处理 |
|---|---|
| 连接测试「连不上」 | 确认 ComfyUI 已启动、`comfy_bridge` 是 `custom_nodes\` 的**直接子目录**、且**重启过** ComfyUI（控制台应有「/chip/* 路由已注册」） |
| `Failed to fetch` | **先看 ComfyUI 是不是真的开着**（最常见原因）。开着的话插件会自动扫常见端口，并在「离线」后每约 15 秒重探一次，ComfyUI 晚启动也会自动连上；仍失败就看启动参数里的 `--port` 手动填并保存 |
| 改了 `panel.js` 没生效 | 插件脚本只在程序启动时注入一次，重启一次主程序 |
| 端口不是 8188 | 不用改，自动探测会命中并记住；也可手动填地址保存（存浏览器 localStorage） |
| 开始后没反应 | 先在 ComfyUI 里手动跑一次 Queue（`/chip/start` 需要一条历史记录才能复用工作流） |
| 送图后节点没变 | 检查画布上「输入图片」节点是否已连线；`IS_CHANGED` 靠文件 mtime，重跑一次即可 |
