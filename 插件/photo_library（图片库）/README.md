# 照片库 · 主程序插件（顶栏主模式）

**独立的纯照片库**，和「打标库」完全分开：不带标签、不带触发词、不掺文件夹归类。

## 显示方式

和「标签库 / 打标模式」一样是**顶栏模式按钮 + 占满主区的整块视图**：顶栏出现 `照片库`，点一下切换；主区全宽、左侧标签栏隐藏。**「🧩 插件」浮层里不再有这一页**（浮层只剩「标签库工具」）。

顶栏按钮与面板均**不带功能图标**（应用户要求删除）；操作按钮上的小图标仍保留。

注册逻辑在 `panel.js` 顶部（与 `comfy_panel` 同一份幂等引导）：运行时加按钮、加 `section.panel.col-right`、搬运面板内容、包装一次 `switchMode` / `renderPlugins`。**主程序一行未改**；删掉本文件夹顶栏按钮与主视图一起消失，ComfyUI 联动插件照常可用。

## 架构

纯前端插件：图片存浏览器 `localStorage`（键 `chip_photo_library_v1`），不调用主程序后端 `api()`、不碰 `data\` 目录、不需要重新打包 exe。

与联动插件的解耦方式：选中图写到 `localStorage` 的 `chip_photo_selected`，同时暴露全局 `window.plGetSelected()`。`comfy_panel` 插件读它即可；**两个插件删掉任一个，另一个照常能用**。

安装：把 `photo_library` 文件夹放在**主程序**的 `插件\` 下（源码启动 = 项目根 `插件\`；exe = exe 旁 `插件\`）。改了 `panel.js` 内容后需**重启一次程序**（插件脚本只注入一次）。

## 用法

- **添加照片**：多选图片，自动压缩到最长边 1024px（JPEG 0.82）后存进本地
- **点一张卡片**：选中/取消选中，顶部选中信息条显示缩略图、文件名、尺寸和大小
- **删除选中** / **清空库**（清空有二次确认）：收在操作条右侧，没有可删内容时不显示
- 到顶栏 **`ComfyUI`** 模式点 **「📚 用照片库选中图」** → 送进工作流（需先在 ComfyUI 画布上连好「输入图片」节点）

## 边界

- 浏览器本地存储约 5MB，图太多会存不下并提示；此时可在联动插件用「从磁盘挑一张」直接送图，不入库存
- 生成图**不会自动进照片库**（按你的要求只显示、不存储）；想把某张生成图留下，请自行保存后从磁盘添加
- 数据跟着浏览器配置文件走，清理浏览器数据会一起清掉；重要图片请自己另存一份
- ComfyUI 联动插件没装时，本插件仍可正常增删查图
