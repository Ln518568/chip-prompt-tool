# chip-prompt-tool
一款集提示词管理、人工图像打标与标签库于一体的轻量级桌面应用。无需安装，助你构建精准的 AI 训练数据集。
# 用户使用手册

> 适用版本：V1.0.0（2026-11-06 起）

---

## 一、这是什么

一个 **Windows 独立桌面小程序**，双击即用，不用装 Python、不用开浏览器。两大用途：

1. **写 Stable Diffusion 提示词**：正向 / 反向两个编辑区，标签卡片式管理，点一下调权重，中文输入自动翻成英文。
2. **给训练集图片打标**（LoRA / 数据集训练用）：看图打标签，最后一键导出每张图同名的 `.txt` 文件。

配套两个仓库：

- **打标库**：打过标的图连同标签存起来，以后遇到相似的图直接套用，不重复劳动。
- **标签库**：3800+ 条中英文对照标词（含分类），可自建分类、自建标词、染色、挂示例图。

---

## 二、安装与启动

1. 把 `chip提示词.exe` 放到一个**固定位置**（例如 `程序\` 文件夹里）。
   - **注意**：程序在 exe **旁边**自动建 `data` 文件夹存所有数据（标签库、打标进度、设置等）。exe 放哪，data 就建在哪，请放好后再开始使用。
2. 双击 exe 启动。首次启动会自动导入内置标签库，稍等片刻即可。
3. 极个别老旧 Win10 电脑启动失败，可能是缺 WebView2 运行时，装一次「Microsoft Edge WebView2 Runtime」即可。
4. **换电脑**：把 exe、`data` 文件夹、（如有）`插件` 文件夹一起拷过去，数据原样保留。

## 四、提示词模式

写 SD 出图提示词的地方。左侧是标签库侧栏，右侧是**正向**、**反向**两个编辑区。

### 4.1 添加标签的四种方式

| 方式 | 操作 |
|---|---|
| 点选 | 点左侧标签库里的标签（显示中文，插入英文），自动加到「当前激活」的编辑框 |
| 手输 | 编辑框内直接打字，**回车**添加；支持一次打多个（逗号分隔）；支持中文，自动翻成英文 |
| 联想 | 输入时下拉联想（最多 8 条，英文+中文对照），点选直接加入，`Esc` 关闭联想 |
| 拖拽 | 把左侧标签直接**拖进**正向 / 反向编辑框 |

- 「当前激活」的编辑框：用鼠标点过哪个框（或框内的卡片），新标签就进哪个框。
- 输入中文时，先在标签库里反查英文（快且准）；库里没有才调用翻译引擎。

### 4.2 管理标签卡片

每个标签是一张卡片：**上行英文 + ✕，下行中文对照**。

- **点选卡片**（可变多张）：选中后高亮。
- **调权重**：选中卡片按 `Alt + ↑ / ↓`，权重 ≠1 时卡片上直接显示 `(tag:1.2)` 样式。
- **删除**：点卡片上的 ✕。
- **复制**：每个编辑区标题栏右侧有「📋 复制」，只复制本区（序列化为英文逗号串，含权重）。
- **清空**：每个编辑区标题栏右侧有「🗑 清空」，只清本区，清空前会确认并告知条数。
- **复制全部**：底部「📋 复制全部（正向 + 反向）」，复制为两行格式：

```text
Positive: masterpiece, girl, long hair
Negative: lowres, bad anatomy
```

### 4.3 从打标库调用标签

在打标库里可以把整套标签「📥 调用」到正向 / 反向提示词（见 6.4），调用后自动切回本模式。

## 五、打标模式

给文件夹里的图片逐张打标签，最后统一导出 `.txt`（供 LoRA / 数据集训练）。

### 5.1 基本流程

1. 点「📂 打开文件夹」，选择图片所在文件夹。
2. 打开后程序**一次性预加载**全部图片和已有标签：
   - 已有同名 `.txt` 的图会自动读入（可接着上次的半成品继续打）；
   - 上次没打完的进度（自动暂存）也会恢复，优先级高于 `.txt`。
3. 顶部显示进度（如 `已打标 8 / 24`），缩略图右下角角标 `✓ 12` 表示该图已打 12 个标签。
4. 逐张打标，最后点「📤 统一导出」。

### 5.2 切换图片

- 点底部缩略图，或按 `←` / `→` 翻页。
- 按 `Tab`（或点「⏭ 下一张未打标」）循环跳到还没打标的图。
- **每张图的标签严格独立**（按图片完整路径记录）：切走自动保留，切回来还在，绝不串台。

### 5.3 打标签

- 添加方式同提示词模式：点左侧标签库、手输回车（支持中文自动翻译）、联想点选、拖拽入框。
- 点标签框下方的「🌐 一键翻译」可双向补齐中英文（触发词不动）。
- 标签框下方的独立输入框占满整行，随打随加。

### 5.4 触发词

- 默认**整个文件夹共用一个触发词**（在标签区置顶显示，样式与普通标签不同）。
- 勾选「**仅本张**」可给当前图单独设触发词，覆盖全局设置。
- 点触发词卡片的 ✕ = 清除触发词设置。

### 5.5 批量与清理

| 按钮 | 作用 |
|---|---|
| 应用到全部 | 把当前图的标签追加到本文件夹所有图（二次确认，可选「只追加未打标的图」） |
| 清除当前图 | 清空当前这张图的标签 + 触发词 |
| 清除本次打标 | 清掉本文件夹**所有图在程序内的打标记录**，回到未打开状态。**不动**：已导出的 `.txt`、打标库存量、图片本体 |

### 5.6 统一导出

- 点「📤 统一导出」一次性写出全部 `.txt`：**与图片同名、放在图片旁边**，内容为英文逗号串，**触发词排第一位**。
- 只有**有标签**的图才会写出，空标签自动跳过（不会覆盖已有成果）。
- 若目标 `.txt` 已存在，会先询问：**覆盖更新 / 跳过不覆盖 / 取消**。
- 导出完成弹窗会列出所有写出位置；只有一个位置时提供「📂 打开该文件夹」按钮。
- `Ctrl + S` = 手动暂存进度（平时也会自动暂存到 `data\打标进度.json`，意外关闭可恢复）。

### 5.7 存入打标库

- 「💾 存入库」：把**当前图**连同标签、触发词存进打标库。
- 「💾 全部存入库」：把本文件夹**所有已打标的图**批量存库（没打标的跳过并提示数量）。
- 入库前会自动补齐未翻译的中文，放心存。

## 六、打标库

打完标的图连同标签存进来的**通用仓库**：不绑定任何文件夹，程序关闭也保留，之后打任何图都能调出来用。

### 6.1 界面

- **左侧文件夹栏**：`全部 / 未分类 / 各自建文件夹`（带条目数），点进去只看该文件夹。
- **右侧卡片网格**：每张卡片 = 缩略图 + 文件名 + 来源文件夹 + 标签预览（固定 3 行高）。
- 顶部有搜索框和「➕ 手动添加」。

### 6.2 选择与操作（类资源管理器）

- 单击选中 / `Ctrl` 加选 / `Shift` 连选 / `Ctrl+A` 全选 / 点空白取消。
- **双击**卡片 = 查看大图；`Delete` = 删除（带确认）。
- **右键卡片**：查看 / 套用到当前图 / 调用到正·负向提示词 / 移动到文件夹 / 复制图片路径 / 删除。
- **右键文件夹**：新建 / 重命名 / 删除（删除后条目自动归入「未分类」，图片与标签不丢）。
- **右键空白处**：新建文件夹 / 添加标图。
- **拖拽**：把卡片拖到左侧某个文件夹即移动；多选时拖一张 = 整批移动。
- 卡片底部操作按钮**悬停才浮现**，平时界面干净。

### 6.3 套用

「套用」= 把库里的标签**追加并去重**到打标模式当前正在打的那张图上（保留已有标签）。在「查看」弹窗里也可以直接套用。

### 6.4 调用到提示词

把库内标签（触发词排第一）去重追加到**提示词模式**的正向或反向，三个入口：卡片右键 / 多选批量条 / 查看弹窗底部。完成后自动切到提示词模式。

### 6.5 再次打标

多选卡片 → 底部「🔁 再次打标」：把这些图载入打标模式（用库内副本预览）改标签，改完逐张同步回库。单张卡片的「🔁 重打」同理。

### 6.6 手动添加

「➕ 手动添加」：不经过打标模式，直接选图片（可多选共用一套标签）→ 填标签（中文自动翻译）→ 填触发词 → 存库。

### 6.7 删除与清空

- 删除单张 / 批量时可二选一：**仅移除记录**（保留库内图片副本，以后可找回）或**连同图片副本一起删除**（有二次确认）。
- 「清空仓库」同样分两档，并会再次确认。**无论哪种，你电脑里的原图都不受影响**。
- 「🌐 翻译未翻译」：一键补齐当前视图内所有未翻译标签并写回库。

## 七、标签库

3800+ 条标词的**管理库**：左侧是分类（手风琴），右侧是标签卡片网格。标签在这里管理后，提示词模式 / 打标模式的左侧栏即时同步。

### 7.1 浏览与搜索

- 左侧顶层分类是带 ▼ 的大条，**同屏只展开一个大分类**；子分类可任意层级嵌套、逐层折叠。
- 「全部」置顶：跨分类汇总所有标签（按英文去重）。
- 顶部搜索框按中英文匹配过滤。
- 双击标签卡片 = 打开「编辑标签」弹窗（改名称 / 内容 / 颜色 / 示例图）。

### 7.2 新建

- 底部「＋ 新建分类」、每个分类层级的「＋ 新建子分类」。
- 「＋ 新建标签」弹窗两个字段：
  - **标签名称** = 中文显示名（存为中文对照）；
  - **标签内容** = 实际插入提示词的英文文本（留空则等于名称）。
  - 弹窗里有分类下拉框，不必先选中分类。

### 7.3 整理

- **右键标签卡片**：复制文本 / 移动到分类 / 重命名 / 删除；多选后可批量移动、批量删除。
- **右键分类**：新建标签 / 重命名分类 / 删除分类。
- **拖拽**：把标签卡片拖到左侧某分类 = 移动到该分类；多选整组搬。

### 7.4 标签染色

设置 → 📚 标签库 →「标签染色」四选一：

| 模式 | 效果 |
|---|---|
| 关闭 | 不上色 |
| 按分类 | 同一分类统一色（点左侧分类前的 🎨 色点设置） |
| 每个标签独立 | 每张卡片单独上色（悬停卡片出 🎨 按钮） |
| 混合 | 分类色打底，单独设色的标签覆盖 |

- 取色用程序内置取色器（12 预设色 + 自定义渐变面板 / 色相 / HEX）。
- 染色会同步到提示词 / 打标模式的左侧栏。
- 设置里的「🧹 清除全部颜色」一键清掉所有分类色与标签色（标签数据本身不动）。

### 7.5 示例图

- 把图片文件**直接拖到标签卡片上**即可挂示例图（可多张）。
- 在「编辑标签」弹窗的示例图区：添加（文件多选或拖入）、‹› 翻页、◀▶ 调序、★ 设为封面（卡片缩略图）、🔄 替换、🗑 删除。

### 7.6 备份

设置 → 📚 标签库：

- **📤 导出备份**：存为 JSON（含分类、分组、中英文标词，**包括你自建的全部内容**）。
- **📥 导入备份**：选文件 → 先预览（备份 N 分类 / M 条 vs 当前 X/Y）→ 二次确认才覆盖写入；文件格式不对只提示、绝不写入。

建议：大改标签库之前先导出一份备份。

## 八、全局填入面板

一个**常驻桌面、置顶显示**的小面板，把程序里写好的提示词整段填进**任何软件**的输入框（微信 / 记事本 / 浏览器 / WebUI……）。

1. 点顶栏「📋 全局填入」显示面板（再点隐藏；按钮高亮表示面板在显示）。
2. 面板里有**正向 / 反向**两个文本框，程序里提示词一改就同步进来；也可以直接在面板里改。
3. 到目标软件的输入框里**点一下放好光标**，再点面板上的「替换为正向提示词 / 替换为反向提示词」——整段填入。
4. 点标题栏 `−` 收成小圆钮「📋 填入」（仍置顶不挡事），点小圆钮展开；点 `×` 关闭（隐藏）。
5. 面板**不抢焦点**；个别管理员权限的窗口不收模拟按键时，会提示「已复制，请 Ctrl+V」手动粘贴。

## 九、设置详解

点顶栏 ⚙ 打开。左侧分类切换，改动**保存后立即生效**，重启后保持。

### 🌐 翻译

- 默认翻译引擎：39 个引擎，分「免费·无需密钥 / 需要密钥 / 离线」三组。
- **默认内置「阿里巴巴 · 免费」引擎，免密钥开箱即用**。
- 选中需要密钥的引擎后，下方会出现对应密钥填写框（如百度 = AppID/Secret）。
- 「✨ 自定义（OpenAI 兼容）」：填 接口地址 / API Key / 模型名，即可用 OpenAI、DeepSeek、通义、Kimi 及各类中转站。

### 🎨 外观

- 界面主题（深色 / 浅色）。
- 光圈颜色：缩略图当前图的高亮光圈，9 色预设 + 自定义取色器。
- **关闭界面动画**：关掉所有切换 / 展开 / 淡入动效，内容直接显示、响应更快（低配置电脑推荐）。

### ⌨ 输入习惯（打标 / 提示词框通用）

- **输入标词后自动添加**：打逗号（`,` 或 `，`）即把前面内容入框，后面接着打。
- **停手一会儿也自动入框**：停顿 N 秒自动入框，秒数 0.5~5 可设（默认 1.5）。
- 两个开关可单开、可都开；都不勾 = 原来的回车方式。
- 注意：最后一段没跟逗号的文字不会自动入框，按回车或开「停手入框」即可。

### 标词显示（三处独立）

打标框 / 标签库 / 打标库各自的显示方式：**双语 / 仅中文 / 仅英文**（默认双语）。无中文翻译的标签自动回退显示英文。
**导出的 `.txt` 始终是英文**，不受此设置影响。

### 📚 标签库

- 标签库界面：**主界面页签**（默认）/ **悬浮弹窗**。
- 标签染色（见 7.4）。
- 📤 导出备份 / 📥 导入备份 / 🧹 清除全部颜色（见 7.4、7.6）。

### 🗂 缓存

- 显示缩略图缓存占用（文件数 / MB），可「🧹 立即清理」（不影响原图与数据，下次自动重建）。
- 启动时自动清理：从不 / 7 天 / 30 天（默认）/ 每次全清。
- 缩略图内存缓存（默认开）：同一张图一次运行只解码一次。

### 🧹 格式化

目前仅有说明文字（功能未开放）。格式化 = 清空 `data` 文件夹回到初装状态，将来开放时会要求二次确认。

## 十、插件

程序支持「ComfyUI 式」插件：

- 检测到插件时，顶栏出现「🧩 插件」按钮，点开浮层（左插件列表 / 右功能面板）。
- **安装**：把插件文件夹放进 exe 旁的 `插件\`；**卸载**：把插件文件夹**删除或移出** `插件\`（只在里面改名不算卸载）。
- **免重启**：运行中增删插件，窗口重新获得焦点或点开浮层时自动刷新。
- V1.0.0 单文件版不含插件文件夹 → 「🧩 插件」按钮不显示属正常；把 `插件\` 放到 exe 旁边即可启用。

## 十一、ComfyUI 联动（可选）

随附 ComfyUI 节点「**全局提示词**」（`插件\com\`）：

- 程序里提示词变化时自动落盘 `data\提示词同步.json`；节点每次执行读这个文件，输出 `positive` / `negative` 两根 STRING，直接连 CLIP 文本编码器。
- 提示词一改，ComfyUI 自动重跑取新值，无需手动复制粘贴。
- 安装：把 `com` 文件夹放进 ComfyUI 的 `custom_nodes\`，按需配置路径（见插件内 README）。

| `Delete` | 删除选中（带确认） | 打标库 |

## 十三、数据文件说明（exe 旁的 `data\`）

| 文件 / 文件夹 | 内容 |
|---|---|
| `tags.json` | 标签库（分类、标词、颜色、示例图索引） |

## 十四、常见问题

**Q：双击 exe 没反应 / 报错？**
A：先弹出的错误窗口里有原因。老旧 Win10 多半是缺 WebView2 运行时，安装即可。

**Q：换电脑后数据没了？**
A：数据在 exe 旁边的 `data\`，必须连同 exe 一起拷贝。若 exe 旁已有旧的 `data`，程序会优先用它而不是内置库。

**Q：标签库里的标签被误删 / 想恢复？**
A：用 设置 → 📚 标签库 → 📥 导入备份，选择之前导出的 JSON；程序也会在某些大操作前自动留 `tags.backup-*.json`。

**Q：导出的 .txt 会覆盖我原有的吗？**
A：导出前会检测同名文件并询问「覆盖 / 跳过 / 取消」，不会静默覆盖。

**Q：打了一半关了程序，进度还在吗？**
A：在。进度自动暂存，下次打开同一文件夹自动恢复；已存在的同名 `.txt` 也会一并读入。

**Q：翻译不工作？**
A：默认引擎免费免密钥；网络异常时换引擎（设置 → 🌐 翻译）或配置自定义 OpenAI 兼容接口。

**Q：界面卡顿？**
A：设置 → 🎨 外观 勾上「关闭界面动画」；定期在 设置 → 🗂 缓存 清理缩略图缓存。

**Q：顶栏没有「🧩 插件」按钮？**
A：说明 exe 旁边没有 `插件\` 文件夹（或里面没有合法插件）。把插件文件夹放好、让窗口重新获得焦点即出现。
